## 📝 Projektin kuvaus
Tämä projekti on Software Engineering -kurssin testiautomaatiodemo. Tavoitteena on osoittaa modernin CI/CD-putken, yksikkötestauksen ja end-to-end (E2E) testauksen integraatio osana ohjelmistokehitystä.
